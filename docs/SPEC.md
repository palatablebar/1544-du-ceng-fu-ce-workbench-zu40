# 镀层复测工作台数据与算法

导入自备批次或复核估计时阅读。先核对下面的字段和时间窗。查看隔离行原因，再核对估计和派发结果。

## 单据

| 字段 | 用途 | 单位 | 有效区间 |
|---|---|---|---|
| `amps` | 槽电流 | A | 60–260 |
| `time_sec` | 浸镀历时 | s | 80–450 |
| `ph_tenth` | 实测酸碱度 | 0.1pH | 35–66 |
| `area_dm` | 挂件总面积 | dm² | 25–183 |
| `filter_days` | 溶液滤芯使用 | 天 | 0–32 |
| `bath_c` | 槽液温度 | ℃ | 35–68 |

`key` 是单号，`cohort` 是作业区，文本先做 NFKC 归一化。`day` 为测量工日，`received` 为到站工日，`revision` 为正整数版次。同版记录出现多个不同测量结果时隔离该单全部版次。缺测可空置，但每条单至少包含四项观测。

`outcome` 与 `result_day` 成对填写。实绩单位为μm。 `observed` 省略时为 `true`，只在留架右截尾场景允许 `false`。

### 原始行业单据

允许使用 `form` 对象代替平铺量测。保留单号、版次、工日和标签等顶层字段。表中的换算为 `(单据值 − 原点偏移) / 倍率`。每行内部校验完成后，与平铺数据使用同一分窗、建模和派单过程。

| 单据组 | 原始字段 | 用途 | 倍率 | 原点偏移 |
|---|---|---|---:|---:|
| 整流电源 | `bath_milliamperes` | 整流器电流毫安 | 1000 | 0 |
| 整流电源 | `bath_seconds` | 进入槽液秒 | 1 | 0 |
| 挂具进槽 | `ph_cent` | 酸碱度百分位 | 10 | 0 |
| 挂具进槽 | `hanger_square_cm` | 挂具面积平方厘米 | 100 | 0 |
| 槽液抄表 | `cartridge_hours` | 滤芯运行小时 | 24 | 0 |
| 槽液抄表 | `liquid_deci_c` | 槽液温度十分度 | 10 | 0 |

示例见 `sample_data/hanger_tickets_form.json`。混合使用两种量测表示，或单据内读数互相矛盾时，保留隔离原因。

## 时序与训练

拟合 `[0,40)`、校准 `[42,62)`、回放 `[65,84)`、当班从 `88` 日起。前三个窗口的入站和结果都须早于窗口终点。到站日晚于截止日的单据在入站隔离。拟合期冻结补值中位数、均值、尺度及训练包络。

| 特征 | 语义 | 公式 |
|---|---|---|
| `current_density` | 平均电流密度 | `amps/area_dm` |
| `amp_minutes` | 单位面积安分 | `amps*time_sec/(60*area_dm)` |
| `ph_distance` | 偏离控制点 | `abs(ph_tenth-49)/10` |
| `filter_load` | 滤芯负载 | `filter_days * area_dm / 100` |
| `warm_rise` | 超温暴露 | `max(0,bath_c-48) * time_sec / 100` |

### CART 槽位厚差回归

枚举满足最小子叶容量的分割点，以节点内平方误差确定分支。同分割收益按特征序号和切点决胜。

本工作台的独立样本校准方式为滤芯龄期调整厚差误差。风险校准无法确认正负样本时转人工判读。连续估计使用独立校准残差计算双侧区间，误差尺度随作业条件变化。分布监测对训练和当班量测比较Hellinger 距离。未知作业区、两项缺测或两项明显超训练包络的单据需要人工判读。

## 分配厚度复测

| 优先级 | 原因码 | 条件 | 处置依据 |
|---:|---|---|---|
| 1 | `DENSITY_LIMIT` | `amps/area_dm > 4.4` | 挂件单位电流超工艺上限 |
| 2 | `AGED_FILTER` | `filter_days >= 24 and ph_tenth >= 55` | 槽液老化，追加厚度复测 |
| 3 | `LOW_LOAD` | `area_dm < 60 and time_sec > 390` | 小挂具长浸镀 |

第一条为暂停规则。其余命中与模型阈值 `2.3` 共同决定是否列入候选。单据所需工位数按 `1 + int(area_dm >= 100)` 计算。均衡策略对分区限额，集中复核策略允许把额度集中投入高风险区。未分派原因在导出的处置记录中保留。签发前核对每张当班单和工位余额。

### 挂件测厚安排

按单位面积电流、面电荷和折温后酸碱度选测点。超流、老化槽液和小挂件的复测位置有区别，按槽汇总测厚仪需覆盖的点数。 在派发环节展开现场安排，或从关联单据回查实际读数。
